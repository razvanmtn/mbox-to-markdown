Markdown output

The download is a zip of Markdown notes with YAML front matter and relative links to attachments. Markdown opens in many tools. One example is opening the folder as an Obsidian vault.

Download selected saves emails.zip. Unzip it and you have one Markdown note per message, plus the attachments that belonged to those messages.

The folders

A message with a usable date is written under its year and month:

2024/03/2024-03-02-hello.md
2024/03/attachments/notes.pdf

The file name starts with the date, then a short form of the subject. Characters that are unsafe in a file name are removed, and emoji are dropped. Names are shortened. A message with no usable date goes under undated/, with undated- in front of the subject.

The date and time come from the message, written in the time zone of the computer that runs the export. If two messages in the same month would get the same name, the later one gets a -2 suffix, then -3, and so on.

The note

Each note starts with YAML front matter. Empty fields are left out. cc and bcc are included when the message has them. Gmail labels come from the X-Gmail-Labels header and are split on commas.

---
type: email
subject: "Hello"
from: "Ada <ada@example.com>"
to: "Grace <grace@example.com>"
date: "2024-03-02"
time: "09:15"
labels:
  - "Inbox"
message_id: "<id@example.com>"
---

The body follows. Attachments are listed at the end as ordinary Markdown links, relative to the note:

## Attachments

- [notes.pdf](attachments/notes.pdf)

That link points at 2024/03/attachments/notes.pdf when the note is 2024/03/2024-03-02-hello.md. Keep the note and the attachments folder together. If you move the note by itself, the link breaks.

If a selected message cannot be converted, it is missing from the folders above and named in export-errors.txt at the top of the zip.

Open the folder

The download is Markdown, a common format that many editors and note apps can open. Unzip emails.zip. The notes are plain .md files, so you can read them in the editor you already use.

One example is Obsidian. Choose Open folder as vault and select the unzipped folder. You can instead copy the year folders into a vault you already have. The properties panel shows the front matter: type, subject, from, to, date, time, labels, and message id, for the fields that message had.

The attachment links are standard Markdown links, not wikilinks. They resolve because attachments/ is next to the note. Search can cover the body and the properties, so a sender, a subject, or a label is enough to find a note. The folders are the date index: year, then month.
