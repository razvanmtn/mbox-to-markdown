What mbox is

Mbox stores many email messages in one file. Gmail, Apple Mail, Thunderbird, Proton Mail, and Fastmail can all export one.

Mbox is a way to keep a whole mailbox in a single file. This app opens that file and writes the messages you choose as Markdown.

One file, many messages

The format is defined by RFC 4155. Inside the file, each message is an ordinary email, as described by RFC 5322. The messages are stored one after another.

A line that starts with From , then a sender and a date, marks where the next message begins. That line is part of the mailbox, not part of the message. When a line inside a message would itself start with From , the file stores an extra > in front of it. This app removes that > when it reads the message.

The app also opens .mbx. That is the same kind of file with a different extension.

Where it is used

  • Gmail. Google Takeout exports Mail as mbox. The steps are in Export mbox from Gmail.
  • Apple Mail. Choose Mailbox, then Export Mailbox. The result is a package. Open the mbox file inside that package.
  • Thunderbird. A local folder is stored as an mbox file, usually with no extension, in the Thunderbird profile.
  • Proton Mail. The Import-Export app can save a folder as MBOX.
  • Fastmail. An account export can include mail as mbox.
  • Unix mail. Many mail servers and older clients, including Mutt, still keep a mailbox as one file.

Why this app uses it

One file is a practical export. You can copy it, put it on a disk, and open it later without the provider. The app reads that copy locally. How this app works is the next step after you have the file.
