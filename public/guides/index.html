Guides

How to export an mbox file, what the format is, how this app converts it, and how to open the Markdown.

If you do not have an export yet, download the sample mailbox and open it with Open mbox.

  • How this app works

    Open an mbox or mbx file in the browser, filter the messages, and download the ones you keep as Markdown with their attachments.

  • Export mbox from Gmail

    Use Google Takeout to save Gmail as an mbox file. Choose labels when All Mail is larger than 1 GB, then open one file in the browser.

  • What mbox is

    Mbox stores many email messages in one file. Gmail, Apple Mail, Thunderbird, Proton Mail, and Fastmail can all export one.

  • Markdown output

    The download is a zip of Markdown notes with YAML front matter and relative links to attachments. Markdown opens in many tools. One example is opening the folder as an Obsidian vault.
