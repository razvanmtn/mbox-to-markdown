Open the app

How this app works

Open an mbox or mbx file in the browser, filter the messages, and download the ones you keep as Markdown with their attachments.

You open one mailbox. The app reads it on this computer, lists the messages, and downloads the ones you choose.

Open a mailbox

Choose an .mbox or .mbx file. Some exports use the .mbx extension for the same kind of file. The mailbox is read in the browser. It is not uploaded.

If you do not have an export yet, download the sample mailbox and open it with Open mbox.

A file larger than 1 GB is refused. If a Gmail export is bigger than that, export a smaller set of labels instead of All Mail.

Clear drops the mailbox from the page and returns to the start.

Narrow the list

Search looks through the sender, the subject, and the labels together.

Add filter narrows the list further. From, To, Cc, Subject, and Label can contain a word, or not contain it. Date can be on, before, or after a day. Attachments can be has any, or has none. Filters combine, so a message has to match all of them.

Hide matches hides whatever the search and filters currently show, then clears the search and the filters. Hide selected hides the checked rows. Restore hidden brings every hidden message back.

All selects every message that was read successfully and has not been hidden, including messages the current search is hiding. Matching selects only the messages in the current search and filters. None clears the selection. A message that failed to parse stays visible, shows its error in place of the subject, and cannot be selected.

Read one message

Select a row to open it. Rendered shows the message after its HTML has been cleaned. Markdown shows the file that will be saved. Copy markdown copies that file. Download attachment saves one attachment. When a message has several, the button opens the list of files.

Download

Download selected builds emails.zip from the checked messages. Each message is a Markdown file, with its attachments beside it. The layout is described in Markdown output.

If a selected message cannot be converted, the zip still downloads. That message is skipped, and export-errors.txt records the subject and the error.
