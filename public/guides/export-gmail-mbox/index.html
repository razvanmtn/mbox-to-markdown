Export mbox from Gmail

Use Google Takeout to save Gmail as an mbox file. Choose labels when All Mail is larger than 1 GB, then open one file in the browser.

Gmail does not hand you an mbox file from the mailbox screen. The export is Google Takeout. Other providers are listed in what mbox is.

Choose Mail

  1. Open Google Takeout while you are signed in to the account you want to export.
  2. Choose Deselect all. Takeout starts with every Google product selected, and you only want mail.
  3. Select Mail.

Keep each file under 1 GB

Mail is exported as MBOX. In the mail options you can include all mail, or choose labels.

All Mail is often larger than 1 GB, and this app refuses a file over that size. Choose the labels you actually want. Takeout writes a separate mbox file for the labels you pick, and you open one file at a time.

The all-mail file is usually named All mail Including Spam and Trash.mbox. It contains spam and trash. A label file is named after the label.

Download and unzip

Continue to the delivery step. Send a download link by email, export once, and keep the .zip format. A large export can arrive as several zip files. Create the export and wait for the email that says your Google data is ready.

Download the zip and unzip it. The mailbox files are under Takeout/Mail/.

Open it here

In the app, use Open mbox and choose that file. How this app works covers filtering, preview, and the download. If the file is still over 1 GB, go back to Takeout and export fewer labels.
