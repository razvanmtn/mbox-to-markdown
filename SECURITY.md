# Security policy

## Supported versions

Security fixes are considered for the current `main` branch, which is version 1.0.x.

## Reporting a vulnerability

Report a security vulnerability through [GitHub private vulnerability reporting](https://github.com/razvanmtn/mbox-to-markdown/security/advisories/new). Do not open a public issue, pull request, or discussion for a suspected vulnerability.

Describe the affected version, what you observed, and the impact. Leave out a public proof of concept until a fix is available.

The app parses a mailbox in the browser on the computer where it is opened. A report is still useful when the issue is in parsing, HTML handling, file names, or the exported archive.

The maintainer will acknowledge a private report, work on a fix, and coordinate disclosure after a fix is ready. There is no bounty program and no guaranteed response time.
