# Support

Questions, bug reports, and feature requests belong in [GitHub issues](https://github.com/razvanmuntian/mbox-to-markdown/issues).

Use the bug report or feature request form so the maintainer has enough context to respond. The maintainer answers when able. There is no support agreement or response-time commitment.

Security vulnerabilities are not handled in public issues. Report those through the private process in [SECURITY.md](SECURITY.md).

For how to run the app and how the export is laid out, see the [README](README.md).
