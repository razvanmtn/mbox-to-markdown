# Code of conduct

Be respectful. Disagree about the code, not the person.

Harassment, insults, and sexual attention are not welcome. Do not publish someone else's private information, such as a home address or a private email address, without their permission.

Razvan Muntian (@razvanmtn) maintains this project and may edit or remove issues, comments, and pull requests that break these rules.

To report a problem, open a GitHub issue and address it to @razvanmtn. The issue is visible to anyone who can see the repository, so leave out details you do not want public.
